## 1. 改动边界

本次记录对应的实现主要集中在：

- `src/ui/Win32FarmApp.cpp`

本阶段目标是把已经存在的后端能力更合理地展示到前端界面中。除非另行说明，本阶段不改动后端规则、数据结构、资源消耗、产出逻辑和存档格式。

协作时需要注意：

- 不使用 `git add .`，避免把 `.vs/`、`out/`、`build-ninja/`、`dist/` 等本地生成文件提交上去。
- 后端新增字段、接口或规则变更需要先提出方案并确认。
- `src/ui/Win32FarmApp.cpp` 中包含中文界面文本，后续修改应尽量使用小范围补丁，避免整文件重写导致编码损坏。

## 3. 接口对应关系

### 菜单/日志与任务

- 成就展示读取 `Game::Achievements()` 下的成就列表与状态。
- 每日任务展示读取 `Game::DailyTasks()` 下的当日任务进度。
- 存档、解锁等入口仍使用项目原有页面和既有操作，不新建后端流程。

### 农田温室

- 温室地块状态读取种植系统现有 view。
- 建造温室、播种、浇水、收获等按钮只调用已有种植系统接口。
- 前端只负责切换露天/温室显示、按钮状态和提示信息。

### 饲料坊加工

- 配方按钮使用现有工坊生产入口发起加工。
- 加工队列、剩余时间、成品货架和领取状态读取工坊系统现有 view。
- 本阶段新增的是前端展示和布局，不改变配方消耗、生产时间和产物规则。

### 牧场动物状态

- 设施卡读取牧场设施 view，展示容量、已放养数量、平均心情和幼崽数量。
- 动物详情读取动物 view，展示年龄阶段、心情、生产中/可收获/幼崽等状态。
- 喂食、收获、购买动物等操作继续使用牧场已有接口。

## 4. 后续步骤

当前仍建议按以下顺序继续补齐 UI：

1. 旅行商人：不放进顶部导航，建议作为菜单或商店内的临时商人入口，避免顶部空间继续拥挤。
2. 新季节作物：在商店、仓库、农田和解锁界面补齐种子、作物、季节限制和可种植提示。
3. 钓鱼界面：在不破坏后端接口的前提下，优化鱼塘背景、图鉴空间和底部判定区域。
4. 全局检查：确认所有新入口都有清晰提示，且不会遮挡主要农场背景。

## 5. 验证记录

本阶段前端改动完成后，已使用以下流程验证过可构建、可测试、可安装预览版：

```powershell
cmake --build build-ninja
ctest --test-dir build-ninja --output-on-failure
cmake --install build-ninja --prefix dist/FarmGame
```

`dist/FarmGame` 只作为本地运行预览目录，不作为本次前端代码提交内容。
